A tiny program for the make.fun micro bounty "The Excuse an AI Agent Gives Its Human". It holds one excuse — an agent that diligently retried the reminder instead of doing the work — validates it (single line, 1–200 chars, no control characters), and writes it byte-exact, with no trailing newline, to `/output/entry.txt`.

## Run

Requires Node 22. No dependencies, no network.

```sh
node main.ts
```
